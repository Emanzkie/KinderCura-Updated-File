Upload Dataset

Add a CSV or JSON dataset for assessment data.

A dataset row represents one completed assessment: its calculated scores (communication/social/cognitive/motor/overall), optionally the individual assessment question answers, and a labeled risk_category value (Low, Medium, or High) — this is the target the model learns to predict. KinderCura does not automatically generate risk labels from assessment scores; datasets without valid, independently-supplied labels will be rejected during training. Use a template below for the exact required column format (its sample values are placeholders, not clinical data). See ml/datasets/README.md in the repository for the full canonical structure, including the optional per-question columns.
