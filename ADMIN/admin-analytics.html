    • Transactions: payment records created in the selected period (by record creation date, the same date the Payments page filters on). A count, not money.
    • Amount recorded: the sum of each record's amount. Only the Paid (collected) row is money received; pending, failed, refunded and other rows show amounts recorded on those records and are not added to collected money.
